### The change — the gid-0 slirp ICMP fix (`fix(net)` / `fix(plan)`)

Add the emulator user to **supplementary gid 0**. podman's `default_sysctls` pins `net.ipv4.ping_group_range="0 0"`; QEMU slirp originates the guest's outbound ICMP through an unprivileged ICMP socket (`SOCK_DGRAM/IPPROTO_ICMP`) opened by the uid-1000 emulator **host** process, which the kernel admits only when some gid of the caller lies in `ping_group_range`. With the range pinned to `0 0`, only supplementary gid 0 qualifies. A file capability is wrong: `setcap` forces glibc `AT_SECURE`, breaking the emulator's `LD_LIBRARY_PATH` lookup of its private `lib64/` tree (`libandroid-emu-tracing.so: cannot open shared object file`).

The install step was also a broken duplicate: it was authored as a `run: |` block whose body was `command=set -e` (a no-op assignment, not errexit) carrying a duplicate copy of the following `command:` block. The step is now ONE valid step — descriptive `run:` prose + the `command:` errexit body — so the gid-0 `usermod` cannot be silently swallowed.

### The diff

`git diff origin/main...HEAD -- charly.yml` is **exactly** the fix: the one-step collapse + the three `usermod -aG` guards (kvm / nobody / root). No other change.
